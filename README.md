# 🧑‍💻 Raphael E. Dacara — Portfolio Website

A minimalist, professional portfolio website showcasing my experience as a Mobile and Full Stack Developer.

---

## 🚀 Tech Stack

| Layer | Technology |
|---|---|
| Framework | [Nuxt 3](https://nuxt.com/) + [Vue 3](https://vuejs.org/) |
| Styling | [Tailwind CSS](https://tailwindcss.com/) |
| Dark Mode | [@nuxtjs/color-mode](https://color-mode.nuxtjs.org/) |
| Language | TypeScript |

---

## ✨ Features

- **Single-page scroll layout** with smooth hash-based navigation
- **Sections:** Hero, About, Technologies, Experience, Projects & Contact
- **Muted Slate dark mode** theme with a smooth toggle
- **Fully responsive** for mobile and desktop
- **Downloadable CV** served from project assets
- **Contact form** with form validation
- **SEO-ready** with semantic HTML and meta tags

## 🛠️ Getting Started

### Prerequisites
- Node.js v18+
- npm or pnpm

### Install & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
